## 二、視覺風格系統

### 色彩(CSS variables)

```css
--paper: #F3F4EF;       /* 主背景,偏灰綠的淺白 */
--ink: #20241F;         /* 主要文字色 */
--muted: #6C7066;       /* 次要文字色 */
--accent: #00723C;      /* 強調色(墨綠),2026-07-28 使用者指定更換為新色票 */

--line: #D9D9CE;        /* 分隔線顏色 */
```
⚠️ 強調色歷經多次反覆調整(黃銅色→灰綠→深綠→翡翠綠→#3D6A43→2026-07-28 更新為 #00723C),**#00723C 為目前最終定案版本**,除非使用者主動要求,不要再更換。

### 字體系統
- **標題**:Fraunces(襯線,帶個性,常搭配斜體強調字)—— Google Fonts
- **內文/UI**:Work Sans
- **標籤/編號/小字/導覽列**:IBM Plex Mono(營造「精確、規格感」的設計師質地)
- **首頁 Hero 大標題**:改用 IBM Plex Mono 粗體(700),而非 Fraunces——使用者希望大標題帶有跟英文小字一致的復古/工程感,這是刻意的例外
- 曾經測試過 Archivo(粗黑無襯線)想模仿參考圖的數字疊字風格,**最終被打回票**,大數字疊字設計維持 Fraunces 版本

### 關鍵設計語言
1. **切角(Chamfer)**:所有方形照片框、按鈕的右下角都有等腰三角形切角,呼應斜線元素,帶一點復古感。三種尺寸:
   - `chamfer-lg`(46px,用於 Hero 大圖)
   - `chamfer-md`(24px,用於一般照片框)
   - `chamfer-sm`(12px,用於按鈕、小方格)
2. **斜線輔助線「／」**:取代死板的圓點分隔,用於區塊標籤(例如「／ Ecommerce」)
3. **大數字疊字**:作品分類的大方格會有巨大的 Fraunces 數字(如「01」),小標籤文字疊壓在數字下半部,並用背景色墊底製造「切斷數字筆畫」的層次感
4. **幽靈字(Ghost text)**:用超大、極淡描邊文字(如「DESIGN」)當背景紋理,不影響閱讀
5. **玻璃質感(Glassmorphism)**:**已經被使用者完全否決、拿掉**,不要再套用玻璃/毛玻璃效果
6. **格線筆記本背景**:也已被否決(雖然使用者喜歡但擔心分散注意力),目前全站維持乾淨背景
7. **微互動**:
   - 作品縮圖 hover 時從低飽和度轉為完整色彩並微幅放大
   - 分類卡片 hover 時整張卡片會有微微的隨機傾斜角度 + 浮起效果(不同卡片傾斜方向不同,避免規律死板)

## 四、Project Detail 頁的三種延伸內容元件(重要,可重複使用的元件庫)

1. **翻頁書(Flipbook)**——用於多頁作品
   - 狀態機邏輯(`views` 陣列):封面(單頁,窄版 240px)→ P0/P1(雙頁並排,寬版 480px)→ P2/P3(雙頁)→ P4/P5(雙頁)→ 封底(單頁,窄版)→ 循環回封面
   - **規則:除了封面本身,之後任何一次翻頁(不論前進/後退),前進只有「右頁」翻動,後退只有「左頁」翻動**,另一側安靜換上新內容,不做翻動畫
   - 封面 ↔ 展開頁之間有「整本書往右滑動置中」的展開/收合動畫(容器寬度 240px↔480px 平滑轉場)
   - 手機版:箭頭按鈕改懸浮半透明疊在書頁上(縮小 15%),封面直接點擊觸發翻開,展開後點擊右半頁/左半頁可直接翻頁(不用精準點小按鈕)
   - ⚠️ **已知問題,使用者反映翻頁動畫還是有點卡頓,已嘗試 will-change 優化跟縮短陰影疊層淡出時間,但使用者說「還是有」,這個問題目前擱置、之後需要回頭處理**
   - 每頁目前用鮮明對比色 + 大字標籤(封面/P.0/P.1...)方便除錯用,正式上線前需要換成真實作品圖片

2. **YouTube 影片嵌入**——標準 iframe,套用 chamfer-md 外框

3. **Before/After 拉桿**——中間可拖曳的圓形把手,左右滑動比較修圖前後差異,適合展示修圖技能

## 六、使用者的溝通與決策偏好(給接手的 AI/設計師參考)

- 使用者會主動觀察、給出非常具體的細節回饋(例如精準指出動畫軸心位置、翻頁方向邏輯),溝通時建議**先複述理解、必要時提出釐清問題,再動手**,避免做錯方向浪費來回

- 對於色彩、間距、動畫時序等細節有很高的敏感度與明確偏好
